# 사찰 넷제로 진단 도구

불교탄소중립실천단 지수화풍 · 2026. 9.

사찰 주소를 넣으면 **공개자료만으로 온실가스 배출량을 어림잡아** 주는 프로그램입니다.
방문하기 전에 **어느 절부터 가야 할지** 정하는 데 씁니다.

녹색사찰 69곳 명단이 들어 있어 **한꺼번에 조회**할 수도 있습니다.

> 만드는 사람을 위한 배경과 규칙은 `CLAUDE.md` 에 있습니다.
> 이 문서는 **쓰시는 분**을 위한 것입니다.

---

## 처음 한 번만 하실 일

### 1. 인증키 두 개를 넣습니다

같은 폴더의 **`키.txt`** 를 메모장으로 열면 두 줄이 있습니다.

```
도로명주소=여기에_승인키
공공데이터포털=여기에_인증키
```

등호 뒤에 각자 받으신 키를 넣고 저장하십시오.

- **도로명주소** 승인키 — business.juso.go.kr 마이페이지
- **공공데이터포털** 인증키 — data.go.kr 마이페이지. **Decoding 키**를 받으십시오

`키.txt` 가 없으면 화면이 만드는 법을 알려 줍니다. 겁내지 마십시오.

### 2. 인증키가 살아 있는지 확인합니다

**`키확인.bat`** 을 더블클릭하십시오. 검은 창이 열리고 주소를 물어봅니다.
그냥 엔터를 누르면 수국사로 확인합니다.

맨 아래에 **"두 키 모두 정상입니다"** 가 나오면 준비가 끝났습니다.

## 쓰실 때

**`화면열기.bat`** 을 더블클릭하십시오. 인터넷 창이 저절로 열립니다.
안 열리면 검은 창에 나오는 `http://localhost:8501` 을 복사해 붙여넣으십시오.

끝내실 때는 **검은 창에서 Ctrl 키를 누른 채 C** 를 누르십시오.

## 화면이 하는 일 — 일곱 칸

### 1. 주소 찾기

**주소를 넣는 것이 가장 확실합니다.** 예: `구산동 314`

절 이름으로도 찾아집니다. 그렇게 찾은 것에는 **`(이름으로 찾음)`** 표시가 붙고,
고르시면 경고가 뜹니다.

> **같은 이름의 다른 절이 아주 흔합니다.** 「실상사」는 전국에 여러 곳이고,
> 「법문사」도 고양시와 파주시에 따로 있습니다.
> 이름으로 찾으셨으면 **주소가 맞는지 꼭 확인하십시오.**

**이름이 아예 등록 안 된 절도 있습니다.** 금산사가 그렇습니다. 이름으로 찾으면
전국의 다른 금산사 열두 곳이 나오는데 **정작 김제 금산사는 없습니다.**
안 나오면 주소로 찾으십시오.

산중 사찰은 지번이 `산 162` 처럼 되어 있고 **(산)** 표시가 붙습니다.
목록에 (산) 이 하나도 없으면 **[산 지번만 찾기]** 단추가 나옵니다.

### 2. 건물 정보

동별 연면적·구조·지붕이 표로 나옵니다.
목조·기와 전각은 **전통**으로 분류되어 태양광 후보에서 빠집니다.

용도지역·용도구역도 함께 나옵니다. 규제를 확인할 첫 실마리입니다.

### 3. 개략 진단

해를 고르고 **[자료 가져오기]** 를 누르면 월별 전기·가스를 한 해치 가져옵니다.
**24번 호출하므로 30초쯤 걸립니다.**

- 공개자료 배출량과 국민 몇 명분
- 난방 부담 지표 (가장 많이 쓴 달 ÷ 가장 적게 쓴 달)
- 태양광 필요용량
- 월별 전기 사용량 그래프
- 신뢰도 — 전기·가스 다 나오면 높음, 전기만 나오면 보통, 없으면 낮음

**이 값은 지번 한 곳 기준입니다.** 전기요금은 전각마다 따로 나오지 않고
특정 건물로 묶여 나옵니다. 고지서가 있으시면 **고지서에 적힌 주소**로
찾으시는 편이 가장 정확합니다.

면적에 견주어 전기가 지나치게 많으면 **"건축물대장에 빠진 건물이 있다"** 고
알려 드립니다. 전기가 부풀려진 것이 아니라 면적이 모자란 쪽입니다.

### 4. 정식 산정 — 엑셀 서식 만들기

「온실가스 배출량 산정 실무용 템플릿」의 활동량 칸을 채워 드립니다.
내려받아 엑셀에서 열면 **5단계 계산이 그대로 돕니다.**

현장에서 확인하신 **LPG·등유·휘발유·경유**를 넣으실 수 있습니다. 모르면 비워 두십시오.

### 5. 저장된 사찰

**[이 사찰 기록에 저장하기]** 를 누르면 `사찰기록.csv` 에 한 줄씩 쌓입니다.
엑셀로 바로 열립니다.

여러 분이 나눠 조회하셨다면 **[나눠 돌린 기록 합치기]** 에 각자의 CSV 를
올리십시오. 겹치면 나중에 저장한 것만 남고, **적어 두신 방문 상태와 메모는
지워지지 않습니다.**

### 6. 명단으로 한꺼번에 조회

`녹색사찰_명단.csv` 의 **69곳을 차례로 조회**합니다.

- **10곳씩** 합니다. 한 곳이 끝날 때마다 저장하므로 **중간에 멈춰도 이어집니다**
- 이미 조회한 곳은 건너뜁니다
- 한 곳이 실패해도 멈추지 않고 사유를 적고 넘어갑니다
- 한 곳에 10~20초. 서버가 느리면 3분에서 끊고 다음으로 갑니다

### 7. 방문 우선순위

**어느 절부터 갈지** 정하는 표입니다. 세 가지를 나란히 보여 드립니다.

| 무엇 | 왜 |
|---|---|
| 배출 규모 | 클수록 줄일 여지가 큼 |
| 난방 부담 | 2.5배 이상이면 **◀** 표시. 난방 개선 여지 |
| 태양광 여지 | 올릴 신식 건물이 있는가 |

**점수를 합쳐 하나로 만들지 않습니다.** 어느 것을 중히 볼지는 사람이 정할 일입니다.

자료가 부족한 곳은 **「판단 보류」** 로 따로 뺐습니다.
우선순위가 낮은 것이 아니라 **현장에서 확인해야 하는** 곳입니다.

## 잘 안 될 때

| 나온 말 | 어떻게 |
|---|---|
| 인증키 파일이 없거나 비어 있습니다 | `키.txt` 에 키를 넣으십시오 |
| 승인키가 올바르지 않거나 기간이 지났습니다 | business.juso.go.kr 마이페이지에서 확인 |
| 등록되지 않은 인증키입니다 | data.go.kr 에서 **Decoding 키**를 받아 넣으십시오 |
| 이 서비스를 쓸 권한이 없습니다 | 활용신청이 승인됐는지 확인. 신청 직후면 하루 뒤에 |
| 제공기관 서버가 잠시 불안정합니다 | **1~2분 뒤에 다시** 눌러 보십시오. 대개 그 사이에 풀립니다 |
| 찾으시는 주소가 없습니다 | 번지를 빼고 동 이름만 넣어 보십시오 |
| 사찰기록.csv 에 쓰지 못했습니다 | **엑셀에서 그 파일을 닫고** 다시 누르십시오 |

## 알아두실 것

**배출계수는 2026년 9월 기준입니다.**
전력은 발전단(LB) **0.3844**, 도시가스는 순발열량 38.9MJ 기준입니다.
기존 다섯 사찰과 비교하실 때만 화면에서 「보고서2024」(0.4747)를 고르십시오.

**공개자료가 잡지 못하는 것** — 계약전력, LPG·등유·화목, 차량, 상수도.
모두 방문해서 확인해야 합니다. 화면에도 그렇게 적혀 있습니다.

**건축물대장이 절마다 편차가 큽니다.** 봉은사는 1.8% 이내로 맞지만
실상사는 71%가 빕니다. 목조 전각이 등재되지 않은 곳이 많습니다.

## 인증키를 남에게 주지 마십시오

**`키.txt` 는 배포할 때 빼십시오.** 나머지 파일만 주시면 됩니다.
받으신 분이 각자의 키를 넣으면 됩니다.

**개인정보는 이 도구에 들어오지 않습니다.** 주지스님 성함·연락처·종단은
`녹색사찰_명단.csv` 에도 `사찰기록.csv` 에도 없습니다. 원본 엑셀에만 두십시오.
기록 파일을 남에게 보내셔도 개인정보가 딸려 가지 않습니다.

## 파일이 하는 일

| 파일 | 하는 일 |
|---|---|
| `화면열기.bat` | **더블클릭하면 화면이 열립니다** |
| `키확인.bat` | 인증키가 살아 있는지 확인 |
| `키.txt` | 인증키 두 줄. **배포할 때 빼십시오** |
| `녹색사찰_명단.csv` | 녹색사찰 69곳. 일괄 조회에 씁니다 |
| `사찰기록.csv` | 저장한 사찰. 없으면 처음 저장할 때 생깁니다 |
| `서식_...템플릿.xlsx` | 엑셀 서식 원본. **고치지 마십시오** |

나머지 `.py` 파일은 프로그램 본체입니다. 건드리지 않으셔도 됩니다.

**모든 파일이 같은 폴더에 있어야 합니다.**

## 파이썬이 없다는 말이 나오면

이 컴퓨터에는 파이썬 3.14 가 깔려 있고 `화면열기.bat` 이 알아서 찾습니다.
다른 컴퓨터에 옮기실 때만 설치가 필요합니다.

https://www.python.org 에서 내려받아 설치하시되, 설치 화면에서
**"Add Python to PATH"** 를 반드시 체크하십시오. 그다음 폴더에서

```
pip install -r requirements.txt
```

를 한 번 실행하십시오.
